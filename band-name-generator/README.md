# Band Name Generator 

A simple Python script that generates a band name based on user inputs for city and pet name.

## How to Run
1. Open a terminal or command prompt.
2. Navigate to this folder.
3. Run: `python band-name-generator.py`

## What I Learned
- Using `print()` to display messages.
- Getting user input with `input()`.
- String concatenation to combine inputs.

## Example Output
Welcome to the Band Name Generator
What city did you grow up in?
New York
What is your pet's name?
Fluffy
Your band name is New York Fluffy
