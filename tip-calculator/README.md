# Tip Calculator

A Python script that calculates the total bill with tip and splits it among people based on user inputs.

## How to Run
1. Open a terminal or command prompt.
2. Navigate to this folder.
3. Run: `python tip-calculator.py`

## What I Learned
- Mathematical operations (addition, division).
- User inputs and type conversion (e.g., float for bill).
- Formatting outputs with f-strings or rounding.
